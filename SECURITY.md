# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within RadarFlow, please send an email to `security@radarflow.io`. All security vulnerabilities will be promptly addressed.

Please include:
- Description of the vulnerability
- Steps to reproduce the issue
- Potential impact and affected endpoints

Do NOT disclose security vulnerabilities via public GitHub issues.
